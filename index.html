How it works

  1. Find the car. Each evening the app asks Tesla's official Fleet API for the car's parked location and heading. Read-only access: it can't unlock, move, or control the car.
  2. Pick the side of the street. It snaps the location to the nearest block in the city's street-sweeping map and works out the side from GPS position and which way the car is facing.
  3. Check tomorrow's schedule. Each block side has its own days, weeks of the month, and hours. Holidays are handled.
  4. Alert. If your side is swept tomorrow you get a push notification with the time window and a map link.
