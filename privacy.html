Privacy

Sweep Alert is a personal, single-user project. It is not a commercial service and is not affiliated with Tesla or the City of San Francisco.

What it accesses

  • Vehicle location and heading, through Tesla's official Fleet API, with read-only scopes (vehicle information and location). It cannot send commands to the car.
  • Public street-sweeping schedules from DataSF.

What it stores

An OAuth refresh token, kept as an encrypted GitHub Actions secret. After each nightly check, the latest parking status (location, street, side and schedule) is published on this site encrypted with AES-256-GCM, using a key derived from the owner's passphrase. It is decrypted only in the owner's browser; the passphrase is never sent to any server. If “Remember on this device” is ticked, it is kept only in that browser. Nothing is shared with third parties.

Notifications

Alerts are sent through ntfy to a private topic.

Revoking access

Access can be revoked at any time from the Tesla account's third-party app settings.
